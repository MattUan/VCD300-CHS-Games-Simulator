# 【VCD300-GAME Simulator · V1.1 beta 升级补丁】

适用于 Windows 10 / 11 x64，基于已能正常运行的 V1.0 beta 或 V1.0.1 beta 目录升级。

## 【安装】

1. 关闭程序，备份原目录的 VCD300.exe。
2. 将补丁里的 VCD300.exe 复制到原程序目录，覆盖同名文件。
3. 启动后标题应显示 VCD300-GAME Simulator · V1.1 beta。

仅运行时只需替换 VCD300.exe。source 是本次更新涉及的源码，可按需复制；开发者应从 GitHub 获取完整源码再构建。原有 vcdcore.dll、zlib1.dll、menus、roms 必须保留，补丁不能单独运行。已有按键及画质配置继续使用；若需回退，关闭程序并恢复备份的 EXE。

## 【本版更新】

- 窗口缩放时保持游戏画面 4:3，底部操作区占用单独高度；拖动任意边或角均等比例调整。
- F11 全屏后保持 4:3，宽屏两侧补黑边，同时隐藏底部按钮、状态文字和输入提示；再次 F11 恢复原窗口及底部操作区。窗口最大化按钮关闭，使用 F11 全屏。
- 标题栏去除中文括号，统一显示名称与 V1.1 beta 版本号。
- 加入原创黄色光盘与手柄图标，含多尺寸 Windows ICO，覆盖窗口和 EXE 图标。
- 合并 V1.0.1：1P / 2P 独立选择键盘或具体手柄，支持键盘+手柄、手柄+键盘；设备连接不自动改变操作方式。USB / XInput 自定义 A、B、SELECT、START 映射生效。

进入双人游戏：主菜单选游戏后，在游戏标题页由 1P 按 SELECT（部分游戏用方向键）选择双人，再按 START。2P 的 START / SELECT 在部分游戏中无功能。

按 joy.cpl 编号设置请选择 USB 条目；如果 7 是 START、8 是 SELECT，则将 START=7、SELECT=8。可用选项内【开始检测按键】核对。XInput 使用界面列出的标准逻辑编号。两位玩家分别保存设置。

## 【验证范围】

通过：22 项输入逻辑检查、408 项几何断言、不同尺寸及仿真开关下的黑边像素检查、标题与嵌入图标、8 个拖动方向、窗口尺寸校正、全屏底栏隐藏与连续往返。800×600 下的游戏仿真输出哈希与 V1.0.1 一致；菜单混合与音频滤波检查结果一致。

本次主程序在 Linux 使用 Mono C# 编译器生成 Windows x64 GUI EXE，UI 检查使用 Mono / Xvfb 和测试专用 Windows API 空输入桩。未进行 Windows 实机、实体手柄验收或全量游戏回归。测试专用配置和桩不随补丁发布。原生内核及音频处理代码不变。
